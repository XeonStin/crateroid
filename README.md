# 弹坑星球 CRATEROID 🐛💥

回合制炮术虫虫对战（百战天虫 / 弹弹堂 like）· 单机 vs AI · 桌面 + 手机触屏

**在线试玩：https://xeonstin.github.io/crateroid/**（手机可直接打开，横屏游玩）

## 本地启动

```bash
python serve.py          # 默认 5610 端口，绑定 0.0.0.0
# 本机    http://127.0.0.1:5610/
# 局域网  http://<启动时打印的IP>:5610/   （手机连同一 Wi-Fi 直接玩）
```

无构建、无外部网络依赖（PixiJS v8 已内置于 `vendor/`）。

## 玩法

- 3v3 回合制炮术对战（世界 1800×1000）：行走 / 跳跃 / 二段跳 / **斜向跳跃（空中左右控制）** / **双击方向冲刺**，鼠标或弹弓拖拽瞄准，蓄力发射
- 完全可破坏地形、每回合随机风场（雪原×1.35 / 沙漠×0.7 等主题倍率）、爆炸击退、摔伤、落水（熔岩）即死
- **发射后有完整 5 秒撤退时间**（可边跑边看弹丸飞行）
- 8 种武器：火箭弹 / 手雷 / 集束炸弹 / 散弹枪（5 弹丸散布·每颗可挖地·2 连发）/ 空袭 / 钻地弹 / 神圣手雷 / 奶牛空袭
- 补给箱伞降：医疗 / 武器 / 工具（喷气背包，按住跳跃推进）
- 第 11 回合突死：水位加速上涨 + 全员 1HP（HUD 始终显示「第 N 回合」）
- 4 张程序化地图（可自定义种子，各有风力/地形/装饰差异）· **5 课教学关卡**（移动/瞄准/武器/地形补给/特殊武器，哑靶陪练）· 6 个挑战关卡（S/A/B 评级）· 战绩存档（localStorage）
- AI 三档：弹道模拟寻优（困难档会走位、换位、选特殊武器、发射后撤退）
- 队伍识别：脚下队伍色光环、队伍色血条边框+数字、敌方虫虫有怒眉
- 暴击系统：爆炸 7% 概率 ×1.6 伤害（金色「暴击！」）
- 背水一战：全队只剩 1 只虫时，移速 +15%、冲刺次数 ×2
- 成就系统：8 个成就（初次胜利/双杀/三杀/神枪手/暴击时刻/毫发无伤/补给大亨/背水一战），金色提示 + 成就墙
- 趣味反馈：双杀/三杀播报、受击眩晕星星、擦身而过「好险！」、击杀嘲讽、结算面板展示发射/命中率/造成与承受伤害/击杀/最远一击
- 今日种子：选图界面一键填入当天日期种子，和朋友玩同一张图

## 操作

| 桌面 | 手机 |
|---|---|
| A/D 行走，W/空格 跳跃（按住=喷气推进） | 左下 ◀ ▶ ⤒ 虚拟键 |
| **空中按住方向 = 斜向跳跃**；**双击 A/D = 冲刺**（每回合一次） | 空中按住 ◀▶ 斜跳；双击 ◀▶ 冲刺 |
| 鼠标瞄准方向，**按住左键：鼠标离虫虫越远力度越大**，松手发射；瞄准中滚轮微调力度 ±2% | 单指按住拖拽=弹弓瞄准，松手发射 |
| 1-8 选武器，Tab 收起武器栏，**Esc / 右键取消瞄准** | 底部武器栏点选 |
| 滚轮缩放（非瞄准时），拖拽平移 | 双指捏合/平移 |
| 空袭/奶牛：选中后按左键进入标记 → 再点地图确认 | 同样：选中后点地图标记 |

> 力度控制可在 设置 → 桌面力度控制 切换：**拖拽距离**（默认，精确）或 **按住蓄力**（经典摆动式，永不粘顶）。

### 四张地图的差异

| 地图 | 风力 | 地形 | 装饰 |
|---|---|---|---|
| 🏝️ 翠绿群岛 | 标准 ×1.0 | 2~3 座浮岛 + 湖 | 棕榈树 |
| 🏜️ 落日沙漠 | **最弱 ×0.7** | 平顶台地 + 缓坡 | 仙人掌 |
| 🏔️ 极光雪原 | **最强 ×1.35** | 高耸雪峰 + 浮岛 | 雪松、极光、星空 |
| 🌋 熔岩星球 | 偏强 ×1.15 | 浮岛 + 地下洞穴 | 发光水晶、火星、岩浆更高 |

## 技术要点

- **PixiJS v8**（WebGL）渲染世界，UI 全 DOM 覆盖层；纯 ES Modules，无构建
- **自研物理**：固定步长 1/60 + 投射物 4× 子步；重力/风/圆碰撞/击退/摔伤
- **可破坏地形**：离屏画布分 8 瓦片 + `Uint8Array` 掩码双源，爆炸只重传脏瓦片（~0.1MB/次）
- **AI**：克隆地形掩码 → 与真实物理共用积分器模拟候选弹道（角度×力度网格+迭代细化）→ 评分（敌伤 − 2.2×友伤 − 1.9×自伤 − 落水险）
- **音频**：WebAudio 全程序化合成 SFX + chiptune 双轨 BGM
- 已知环境坑与自动化测试方法见 [TESTREPORT.md](TESTREPORT.md)
