# 弹坑星球 CRATEROID 🐛💥

回合制炮术虫虫对战（百战天虫 / 弹弹堂 like）· 单机 vs AI · 桌面 + 手机触屏

**在线试玩**：[https://xeonstin.github.io/crateroid/](https://xeonstin.github.io/crateroid/)（手机可直接打开，横屏/竖屏均可游玩）

## 本地启动

```bash
python serve.py          # 默认 5610 端口，绑定 0.0.0.0
# 本机    http://127.0.0.1:5610/
# 局域网  http://<启动时打印的IP>:5610/   （手机连同一 Wi-Fi 直接玩）
```

无构建、无外部网络依赖（PixiJS v8 已内置于 `vendor/`）。

## 玩法

- 3v3 回合制炮术对战（世界默认 1800×1000，选图时可切 **小/中/大** 三种宽度）：行走 / 跳跃 / 二段跳 / **斜向跳跃（空中左右控制）** / **双击方向冲刺**，鼠标或弹弓拖拽瞄准，蓄力发射
- 完全可破坏地形、每回合随机风场（雪原×1.35 / 沙漠×0.7 等主题倍率）、爆炸击退、摔伤、落水（熔岩）即死
- **发射后有完整 5 秒撤退时间**（可边跑边看弹丸飞行）
- 9 种武器：火箭弹 / 手雷 / 集束炸弹 / 散弹枪（5 弹丸散布·每颗可挖地·2 连发，蓄力收束散布）/ 空袭 / 钻地弹 / 神圣手雷 / 奶牛空袭 / **传送**（点地图瞬移，每队初始 1 次）
- **场景油桶**：开局随机分布在平坦地表，被爆炸或散弹波及会延迟引爆并连锁（同种子桶位相同）
- 补给箱伞降：医疗 / 武器 / 工具（喷气背包，按住跳跃推进）；AI 也会顺路捡箱
- 第 11 回合突死：水位上涨（熔岩图翻倍）+ 全员压到 **25 HP**（HUD 始终显示「第 N 回合」）
- **主题机制**：雪原**冰面打滑**（走位带惯性、击退滑行）/ 沙漠**回合内阵风漂移** / 熔岩突死涨水×2——选图即选战术
- 4 张程序化地图（可自定义种子，各有风力/地形/装饰差异；选图时可选 **小/中/大** 地图宽度）· **4 课分步教学 + 练习靶场**（移动/瞄准/武器/特殊武器，逐步目标判定，靶子不会还手）· 6 个挑战关卡（S/A/B 评级）· 战绩存档（localStorage）
- AI 三档：弹道模拟寻优（困难档会走位、换位、选特殊武器、发射后撤退；普通档首发更歪更像人）
- 队伍识别：脚下队伍色光环、队伍色血条边框+数字、敌方虫虫有怒眉
- 暴击系统：**弹丸直接命中虫体必暴击**（1.6×），爆炸另有 7% 随机暴击（金色「暴击！」）
- 背水一战：全队只剩 1 只虫时，移速 +15%、冲刺次数 ×2
- 成就系统：**20 个成就**（含地形杀/掘地三尺/天降奶牛/弹无虚发/濒死反杀/突死幸存/空中接箱等），金色提示 + 成就墙
- 趣味反馈：双杀/三杀播报 + **击杀慢镜头**、爆炸**焦痕**留在战场上、**上一发弹道残影**（学习工具）、受击眩晕星星、擦身而过「好险！」、击杀嘲讽、结算面板展示发射/命中率/造成与承受伤害/击杀/最远一击
- 主题 BGM：同一首萌曲按地图变调变速（雪原慢速三角波 / 熔岩快速亮音）
- 今日种子：选图界面一键填入当天日期种子，和朋友玩同一张图

## 操作

| 桌面 | 手机 |
|---|---|
| A/D 行走，W/空格 跳跃（按住=喷气推进） | 左下 ◀ ▶ ⤒ 虚拟键 |
| **空中按住方向 = 斜向跳跃**；**双击 A/D = 冲刺**（每回合一次） | 空中按住 ◀▶ 斜跳；双击 ◀▶ 冲刺 |
| 鼠标瞄准方向，**按住左键：鼠标离虫虫越远力度越大**，松手发射；瞄准中滚轮微调力度 ±2%；**↑/↓ 微调角度（Shift 细调 0.25°）** | 单指按住拖拽=弹弓瞄准，松手发射 |
| 1-9 选武器，Tab 收起武器栏，**Esc / 右键取消瞄准**，**P 跳过回合** | 底部武器栏点选 |
| 滚轮缩放（非瞄准时），拖拽平移 | 双指捏合/平移 |
| 空袭/奶牛/传送：选中后按左键进入标记 → 再点地图确认 | 同样：选中后点地图标记 |

> 力度控制可在 设置 → 桌面力度控制 切换：**拖拽距离**（默认，精确）或 **按住蓄力**（经典摆动式，永不粘顶）。

### 四张地图的差异

| 地图 | 风力 | 地形 | 机制 | 装饰 |
|---|---|---|---|---|
| 🏝️ 翠绿群岛 | 标准 ×1.0 | 2~3 座浮岛 + 湖 | — | 棕榈树 |
| 🏜️ 落日沙漠 | **最弱 ×0.7** | 平顶台地 + 缓坡 | 回合内**阵风漂移** | 仙人掌 |
| 🏔️ 极光雪原 | **最强 ×1.35** | 高耸雪峰 + 浮岛 | **冰面打滑**（惯性走位） | 雪松、极光、星空 |
| 🌋 熔岩星球 | 偏强 ×1.15 | 浮岛 + 地下洞穴 | 突死**涨水 ×2** | 发光水晶、火星、岩浆更高 |

## 技术要点

- **PixiJS v8**（WebGL）渲染世界，UI 全 DOM 覆盖层；纯 ES Modules，无构建
- **自研物理**：固定步长 1/60 + 投射物 4× 子步；重力/风/圆碰撞/击退/摔伤
- **可破坏地形**：离屏画布分 6 瓦片 + `Uint8Array` 掩码双源，爆炸只重传脏瓦片（~1.6MB/次）；焦痕烘焙在瓦片画布上随爆炸一起被炸掉
- **AI**：克隆地形掩码 → 与真实物理共用积分器模拟候选弹道（角度×力度网格+迭代细化）→ 评分（敌伤 − 2.2×友伤 − 1.9×自伤 − 落水险）
- **音频**：WebAudio 全程序化合成 SFX + chiptune 双轨 BGM（按主题变调变速）
- 已知环境坑与自动化测试方法见 [TESTREPORT.md](TESTREPORT.md)
